# Etsy PNG Sample Pack

The selected shop edition supplies the artwork and links. ZIP names include the
game filename and brand ID, for example:
`80s-music-bingo-all-occasions-bingo-png-sample-pack.zip`.

Paths inside the ZIP are the same for every game and shop:

| Path | Contents |
| --- | --- |
| `full-size-cards/card-01.png` to `card-20.png` | Up to 20 existing full-size cards |
| `two-up-cards/two-up-01.png` and `two-up-02.png` | Up to two sheets of existing cards |
| `extras/bingo-markers-large.png` | Large marker sheet |
| `extras/bingo-markers-small.png` | Small marker sheet |
| `extras/complete-songlist-01.png` | Complete Songlist; additional pages use 02, 03, etc. |
| `instructions/instructions-100-cards.png` | Instructions showing 100 cards |
| `instructions/instructions-200-cards.png` | Instructions showing 200 cards |
| `instructions/instructions-300-cards.png` | Instructions showing 300 cards |
| `assets/preview-qr.png` | Embedded-preview QR |
| `assets/bingo-marker.png` | Uploaded marker source artwork |

Exports keep the existing PNG rendering, dimensions and sample counts. Card
arrangements are not regenerated. PDF filenames and exports are unchanged.

This filename contract is intended for future Keynote automation. No Keynote or
AppleScript automation is included yet.
